# 配置

可向构造函数或 `init_app` 传入映射或 `XXLJobConfig`。所有配置会在挂载路由前完成校验。

| 分组 | 配置项 |
| --- | --- |
| 核心 | `XXL_JOB_ENABLED`, `XXL_JOB_ADMIN_ADDRESSES`, `XXL_JOB_ACCESS_TOKEN`, `XXL_JOB_EXECUTOR_APP_NAME`, `XXL_JOB_EXECUTOR_ADDRESS`, `XXL_JOB_ROUTE_PREFIX` |
| 注册 | `XXL_JOB_AUTO_REGISTER`, `XXL_JOB_DEREGISTER_ON_EXIT`, `XXL_JOB_REGISTRY_INTERVAL` |
| HTTP | `XXL_JOB_HTTP_CONNECT_TIMEOUT`, `XXL_JOB_HTTP_READ_TIMEOUT`, `XXL_JOB_ADMIN_RETRY_COUNT`, `XXL_JOB_ADMIN_RETRY_BACKOFF`, `XXL_JOB_ADMIN_FAILOVER_ON_HTTP_ERROR`, `XXL_JOB_ADMIN_FAILOVER_ON_INVALID_JSON`, `XXL_JOB_ADMIN_FAILOVER_ON_BUSINESS_ERROR` |
| 限制 | `XXL_JOB_CALLBACK_MESSAGE_MAX_LENGTH`, `XXL_JOB_MAX_REQUEST_SIZE`, `XXL_JOB_MAX_PARAM_LENGTH`, `XXL_JOB_CALLBACK_BATCH_MAX_SIZE` |
| 日志 | `XXL_JOB_LOG_ENABLED`, `XXL_JOB_LOG_FILE_ENABLED`, `XXL_JOB_LOG_CONSOLE_ENABLED`, `XXL_JOB_LOG_LEVEL`, `XXL_JOB_LOG_FORMAT`, `XXL_JOB_LOG_DATE_FORMAT`, `XXL_JOB_LOG_PATH`, `XXL_JOB_LOG_FILENAME`, `XXL_JOB_LOG_ENCODING`, `XXL_JOB_LOG_MAX_BYTES`, `XXL_JOB_LOG_BACKUP_COUNT`, `XXL_JOB_LOG_PROPAGATE` |

Admin 地址可以是字符串或序列。重试和故障转移都有明确上限；除非显式启用，否则业务错误不会触发故障转移。`XXL_JOB_ENABLED=False` 时，Admin 操作会短路，协议路由返回业务失败结果。
